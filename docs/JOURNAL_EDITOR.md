# Компоновка страниц дневника · первый рабочий срез

Запуск: `npm ci`, `npm run dev`. Открыть адрес Vite → «Дневник → Компоновка страниц».

## Работа

1. Нажать «+ Страница», задать название и раздел справа. Кнопки «Раньше/Позже» меняют порядок, ссылки используют устойчивый ID. Рецепты остаются в прежнем разделе «Дневник и Выводы».
2. Найти термин, цитату, группу, вывод или ссылку в библиотеке слева и перетащить на лист. Клик по библиотеке также добавляет запись. Источник остаётся единым: удаление или дублирование представления не создаёт новый факт.
3. Перемещать запись мышью. Размер меняется квадратной ручкой справа внизу. Позиции привязываются к шагу 0,01. Поля справа позволяют точную корректировку, выбор шрифта/слоя и выравнивание по центру. На узком экране лист прокручивается горизонтально.
4. Для группы нажать «Создать рукописный овал», затем двигать точки. Можно вытянуть область или подогнать размер под количество слов. Термины, порог и варианты гипотез редактируются в существующем разделе «Дневник и Выводы».
5. Выбрать запись → «Нарисовать линию к». Выбрать линию на листе; перемещать контрольные точки, добавлять/удалять промежуточные точки, включать стрелку/кривую. Маршрут намеренно не приклеивается к перемещаемым записям: автор корректирует его отдельно.
6. Для потенциального противоречия выбрать цитату → «Сопоставление цитат» → вторую цитату с любой страницы. Это создаёт предусмотренное игровым контрактом `compare`. В настройке визуальной линии открыть «Активация линии → Выполнены действия» и выбрать ID созданного действия. Простая линия не создаёт противоречия автоматически.
7. Настроить видимость страниц/элементов, доступность действий и активацию линий через отдельные списки требований. Все перечисленные требования объединяются И. Версия 1 поддерживает terms/conclusions/completed; не добавляет несовместимый язык переменных.
8. Включить «Предпросмотр игрока». Переключать отдельные полученные записи в произвольном порядке, гипотезы и завершённые действия. Скрытые элементы отсутствуют, остальные не меняют координат. Клик по двум цитатам выполняет доступное сравнение; выбор первой цитаты переносится при переходе по ссылке.
9. Изменения сохраняются в локальном хранилище. «Сохранить проект» записывает существующий `project.narrative.json`. Импорт/скачивание проекта и файла layout доступны в прежней панели «Экспорт в Godot». Общая синхронизация и CLI `npm run export-godot -- <папка игры> <файл проекта>` включают `content/journal/journal_layout.json`. Исправить ошибки проверки до синхронизации.

## Контракт и границы

Источник схемы — игра: JOURNAL_LAYOUT_CONTRACT.md и копия journalLayoutSchema.json. Новые данные — необязательный journal_layout в прежнем NarrativeProject версии 1. Камера, выделение, панели и состояние предпросмотра не сохраняются в layout. SVG выбран для бумажных областей и нормализованных контрольных точек; существующий @xyflow/react продолжает обслуживать граф диалогов. Новых зависимостей нет. CLI использует тот же компилятор, что и браузер.

Не реализована полная заявленная программа: нет нативной привязки testimony_links/NPC testimony к журналу; цитаты ссылаются на существующие terms и должны выдаваться штатным grant_term. Скрытые воспоминания не копируются в дневник. Нет редактирования параметров анимации/сюжетных effects, переменных в условиях layout, отдельной темы страницы, автоматического анализа достижимости выводов, точного детектора пересечений кривых с текстом, произвольного рисования новых точек контура, undo/redo и multi-select. Нельзя настроить все варианты revise через UI (импорт/экспорт сохраняет их). Предпросмотр не воспроизводит физику, шрифты и анимации Godot; выбор гипотез управляется флажками и не является полной симуляцией JournalReasoning. Проверка наложений консервативна: взаимоисключающие альтернативы могут давать предупреждения.

Дублирование страницы создаёт новые визуальные ID и копии её линий; логические действия и внешние ссылки остаются прежними и требуют авторской настройки. Удаление записей/страниц оставляет внешние логические ссылки для явного исправления валидатором. Прямая синхронизация в пользовательскую игровую папку в этой сессии не запускалась; общий CLI проверен во временной папке.

Следующий шаг: согласовать адаптер полученных свидетельств testimony_links с игровым загрузчиком, затем расширить редактор логических действий и точный предпросмотр. Не считать всю программу дневника завершённой.
