# DRINK-DIALOGUE-01: рецепты и ожидание напитка

Дата: 2026-11-12. Добавлены вкладка «Напитки», авторский рецепт с посудой, компонентами, миллилитрами и допуском, а также `drink_gate` на узле диалога. Автор задаёт ожидаемый напиток, продолжение после подачи или глотка, отдельные реакции на другие рецепты и общий исход. Граф показывает ветки, симулятор позволяет выбрать напиток, валидатор проверяет ID/ссылки/состав/вместимость. Экспорт создаёт `content/drinks/narrative_drinks.json` и сохраняет `drink_gate` в файле диалога. Игровая сторона реализована в репозитории Dark Alone.

Проверки: `npm run build` PASS; `node --test tests/drink-dialogue.test.mjs` с `NODE_OPTIONS=--experimental-strip-types` — 3/3 PASS. Полный `npm test` — 20/21 PASS: прежний тест `неизменённый проект даёт шесть прежних файлов побайтно` ожидает другой SHA256 для `characters/arkadiy.json`; изменение экспортёра в этой задаче касается только нового файла рецептов и нового поля узла диалога, профиль персонажа не менялся. Установленный Node 22.14 требует экспериментальный флаг для TypeScript; README требует 22.18+.

Текущий каталог материалов содержит тестовые ингредиенты и две подаваемые ёмкости. Пользовательский проект не переписывался; сцену Веры пока не добавляли. Коммита и публикации нет.
