# ADR-0001 · Авторский дневник

2026-11-06 · принято в рамках вертикального среза по заданию владельца.

Использовать контракт 1 существующего Godot-загрузчика без расширений. NarrativeProject получает необязательный journal_layout, старые проекты и файлы экспорта сохраняются. Визуальные связи и сравнения разделены. Нормализованная рабочая область рисуется SVG; существующий React/Zustand и экспорт используются повторно. JSON Schema копируется из игры и проверяется небольшим валидатором используемого подмножества, не объявленным универсальным JSON Schema-движком.

Последствия: нет нового runtime-языка, скрытые NPC testimonies не выдаются автоматически. Интеграция testimony_links и дополнительные сценарные эффекты требуют следующего согласованного изменения. См. JOURNAL_EDITOR.md, JOURNAL_LAYOUT_CONTRACT.md.
