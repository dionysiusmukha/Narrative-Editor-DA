# Руководство для сценариста

## Запуск

```powershell
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Черновик сохраняется в браузере. В разделе «Экспорт в Godot» его можно записать в `project.narrative.json`, скачать и импортировать на другом компьютере. При первом запуске браузер подхватывает проект с сервера, если локального черновика ещё нет.

## Воспоминание и диалог

1. В «Событиях» создайте событие. Впишите стабильный ID и описание произошедшего.
2. В карточке NPC откройте «Память, знания, убеждения и свидетельства». Выберите «Память» и нажмите «+ Запись». Укажите исходное событие, содержание, интерпретацию, эмоцию, значимость и уверенность. Для знания или убеждения выберите соответствующую вкладку.
3. В графе откройте узел, к которому ведёт ответ игрока. Добавьте эффект «Событие NPC», выберите «Запомнить событие» и укажите ID из реестра.
4. Для последующей реплики добавьте условие `memory_<id> == true`. Если она должна появляться после первой смены, добавьте `narrative_shift > 1`. Проверьте, что у диалога указан нужный персонаж.
5. Откройте симулятор, выберите диалог и нужный ответ. Перейдите к следующей смене и проверьте инспектор. Для альтернативной ветки нажмите «Сброс».

## Пример Аркадия

1. В «Экспорт в Godot» откройте «Пример памяти Аркадия». Перед заменой текущего проекта скачайте копию, если хотите сохранить черновик.
2. В симуляторе выберите `[TEST] Аркадий помнит`. В смене 1 ответьте «Говори короче». В смене 2 выберите «Аркадий, ты хотел поговорить?», затем извинитесь. Инспектор показывает старое воспоминание и новое, а в смене 3 доступен более тёплый ответ.
3. Сбросьте симуляцию и выберите сочувствие в первой смене. Во второй доступен вопрос «Как ты после нашего разговора?».
4. Начиная со смены 2 выслушайте ночное свидетельство Аркадия. Затем переключитесь на Воронова и ночного сторожа и выслушайте их. Вернитесь к Аркадию. Все три показания открывают ответ «У меня теперь три разных рассказа».
5. Чтобы просмотреть показания вместе, откройте «События» → «Свидетельства», выберите `incident_night_01` и посмотрите пометки о противоречиях. [Работа со свидетельствами](TESTIMONY_SYSTEM.md).

Проверьте список ошибок на экране экспорта, затем скачайте отдельные JSON или синхронизируйте в подготовленную папку. [Подключение файлов в Godot](GODOT_INTEGRATION.md).
