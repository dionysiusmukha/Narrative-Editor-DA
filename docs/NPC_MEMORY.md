# Память персонажей

Zustand хранит авторский проект. Опциональное поле `narrative_events` содержит определения событий. У события есть стабильный `id`, объективное описание `fact`, массив `records` и при необходимости триггер успешной подачи `service`. Проекты v1 без этих полей открываются с пустым реестром.

| Вид записи | Общие поля | Дополнительные поля |
| --- | --- | --- |
| `memory` | `id`, `character_id`, `text` | `interpretation`, `emotion`, `significance`, `confidence` |
| `knowledge` | `id`, `character_id`, `text` | Информация, которую автор события открывает конкретному NPC |
| `belief` | `id`, `character_id`, `text` | Субъективное утверждение конкретного NPC |
| `testimony` | `id`, `character_id`, `text` | `event_id`, `source`, `related` |

Уверенность и значимость лежат в диапазоне от 0 до 1. ID записи уникален в пределах её вида. Событие может содержать несколько записей для разных персонажей. Новое убеждение или изменение отношения можно оформить новым событием. Диалог проверяет его вместе с прежним воспоминанием. Знания между NPC передаются только через авторские события.

Данные можно редактировать из раздела «События» или из карточки персонажа. Поле исходного события указывает, при каком срабатывании появится запись. Карточка показывает связанные диалоги. Редактор блокирует удаление записей с оставшимися ссылками и показывает их ID. После создания ID фиксируется, чтобы редактирование текста не меняло ссылки и сохранения игры.

В симуляторе динамическая история хранит номер первого срабатывания каждого события. Смена переносит эту историю, термины и выводы дневника. Обычные переменные и список выполненных эффектов сбрасываются к новой сессии, как в игре. «Начать встречу» сохраняет историю текущей смены, «Сброс» возвращает исходное состояние. Инспектор показывает записи выбранного NPC и смену получения. Симуляция живёт в открытой вкладке «Симулятор» и не входит в файл проекта или экспорт.

Условия появления записи задаются на ответах графа, ведущих к узлу с эффектом `remember`. Время получения определяется во время симуляции или игры. [Условия и эффекты](GODOT_INTEGRATION.md) · [Пошаговая проверка](NARRATIVE_EDITOR_GUIDE.md).
