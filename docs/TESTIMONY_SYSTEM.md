# Свидетельства

У свидетельства есть два события. Контейнер определяет, когда игрок услышал рассказ. Поле `event_id` указывает, о каком происшествии говорит персонаж. Поле `source` описывает источник, а `related` содержит ссылки вида `fact_<id>` и `belief_<id>`. Персонажи могут описывать одно событие разными словами и приходить к разным выводам.

Откройте «События» → «Свидетельства». Создайте запись, укажите говорящего, утверждение, источник, событие получения и происшествие. Выберите фильтр по происшествию, чтобы увидеть все версии вместе. У каждой записи можно добавить связь с другой версией и пометить её как возможное противоречие. Список показывает оба конца и тип связи. Истинность утверждений оценивает сценарист или игрок.

Ручные связи между свидетельствами хранятся в `testimony_links` внутри `project.narrative.json`. Godot v1 получает сами свидетельства и их ссылки на факты и убеждения. Граф противоречий и сопоставление показаний в дневнике игры требуют дальнейшей интеграции.

Чтобы новый ответ зависел от полученного рассказа, используйте условие `testimony_<id> == true`. В отличие от личного знания NPC это признак того, что свидетельство уже получено игроком. Пример содержит три версии `incident_night_01`, которые открывают общую реплику только после сбора всех показаний. [Пример проекта](../examples/arkadiy-memory.narrative.json).
